# Suojasiipi - Turvaa ja Tukea Kiusaamista Vastaan

Suojasiipi on moderni alusta psykologisen turvallisuuden edistämiseen ja kiusaamisen ehkäisyyn. Projekti yhdistää tutkimustiedon, interaktiiviset simulaatiot ja dokumentointityökalut yhdeksi saumattomaksi kokonaisuudeksi.

## Pääominaisuudet
- **Valmennuskeskus**: Interaktiivisia harjoituksia ja simulaatioita (Kiusaamisen lukutaito, Bystander-harjoitukset).
- **Aikajana & Raportointi**: Työkalut tapausten faktapohjaiseen dokumentointiin.
- **Tekoäly-asiantuntijat**: Tutkimustietoon perustuvat avustajat eri rooleille.

## Kehitysympäristö

1. Asenna riippuvuudet:
   ```bash
   npm install
   ```

2. Käynnistä kehityspalvelin:
   ```bash
   npm run dev
   ```

3. Build-versio:
   ```bash
   npm run build
   ```

## Teknologiat
- Next.js 15
- Tailwind CSS
- Framer Motion
- Lucide React
